# Конвертер единиц измерения

## Назначение проекта

Консольная программа для перевода одних единиц измерения в другие.  
Пользователь выбирает тип преобразования из меню, вводит исходное значение, программа выводит результат.

## Какие задачи решает программа

- Переводит градусы Цельсия в градусы Фаренгейта
- Переводит километры в мили
- Переводит килограммы в фунты
- Переводит метры в футы
- Переводит литры в американские жидкие галлоны (1 галлон = 3.785411784 л)
- Переводит мегабайты в гигабайты (1 ГБ = 1000 МБ)
- Позволяет выполнять несколько преобразований подряд
- Обрабатывает некорректный выбор пункта меню
- Проверяет корректность введённого числа (не допускает отрицательные значения и нечисловой ввод)

## Инструкция по запуску

1. Убедитесь, что установлен Python 3.7 или новее.
2. Откройте терминал в папке с файлом.
3. Выполните команду:

```bash
python variant2_converter.py
```

## Как пользоваться программой

1. При запуске программа выводит меню с шестью вариантами преобразования.
2. Введите номер нужного преобразования (от 1 до 6).
3. Введите исходное значение.
4. Программа выведет результат конвертации.
5. Если введён неверный номер или некорректное число — программа сообщит об ошибке и попросит ввести данные заново.

6. После результата ответьте на вопрос «Выполнить ещё одно преобразование? (да/нет):».
7. Ответ «да» возвращает в меню, «нет» завершает программу. Регистр букв и пробелы по краям не влияют на ответ. При другом ответе программа повторяет вопрос.

## Пример работы программы

```
=== Конвертер единиц измерения ===

Выберите конвертер:
1. Градус Цельсия -> Градус Фаренгейта
2. Километры -> Мили
3. Килограммы -> Фунты
4. Метры -> Футы
5. Литры -> Американские галлоны
6. Мегабайты -> Гигабайты

Ваш выбор: 1
Введите температуру (°C): 36

36.0 C = 96.8 F

Выполнить ещё одно преобразование? (да/нет): нет
Работа программы завершена.
```
